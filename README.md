Feito com: Unity 6 C# 
Sobre o projeto: Temos um personagem como o zumbi do minecraft, que está em uma  floresta e tem que coletar algumas cartolas pela floresta. 
O que o projeto faz: o jogador movimenta o personagem com as setas/WASD e consegue pular com espaço, ao encostar nas cartolas o personagem consome elas
Cenas: Floresta durante o dia 
Scripts: 
movimento: define teclas de movimento e salto, junto a isso define velocidade de caminhada e salto 
rotator: faz objetos coletáveis ficarem rodando 
coletavel: quando identifica colisão deleta o coletavel(vai no jogador) 
camera: faz a câmera acompanhar o jogador 
Objetos principais: 

StanleyKubrick(jogador)
Chão, sendo a floresta(mapa)
Conjunto de blocos e cores para o cenário(dentro de Mapa)
Cartolas(coletavel)
câmera(uma câmera que segue o jogador)
Recursos usados: Rigidbody, Collider com Is Trigger, mesh collider, capsule collider, box collider, character controler, camera light

Controles Setinhas/WASD: movimentam o personagem 
espaço: faz o personagem pular 
O que eu aprendi:  Mais lógica de programação, modelação básica no Blender e usar texturas na Unity

Como abrir
Baixe o projeto, abra o Unity Hub, clique em Add e escolha a pasta do projeto.
